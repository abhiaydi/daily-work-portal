# Daily Work Portal

Daily planning, extra work, closure reports, reviews, sales meetings and dashboards.

- `index.html` — the portal (served by GitHub Pages)
- `config.js` — database address and public key
- `supabase/` — database setup, security rules, reminder schedule and server functions (AI, emails)
- `SETUP.md` — step-by-step setup

The staff list is stored in the database, not in this repository.
